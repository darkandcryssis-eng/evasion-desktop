# Кандидаты стратегий для живого подбора

Готовые конфиги для ручной проверки обхода на этапе 1 (`run --mode intercept`).
Нужны, пока нет автоподбора (`blockcheck`/генератор): кладутся в репозиторий,
чтобы не создавать JSON руками (путь и метка BOM уже спотыкали запуск).

Все файлы — без BOM, с одинаковыми группами, точкой наблюдения и контрольными
целями; различается только стратегия. Радиус: `video` (youtube и соседи) и
`discord`.

## Что в каждом

| Файл | Приём | Идея |
|---|---|---|
| `fake-badsum.json` | фейк с битой суммой TCP + мусорное тело, затем реальный | DPI впитывает фейк (сумму не проверяет), сервер его отбрасывает; хоп-считать не нужно |
| `fake-ttl.json` | фейк с низким TTL (6) + мусорное тело, затем реальный | фейк долетает до DPI, но умирает до сервера; TTL — подбираемый |
| `fake-split-sni.json` | фейк (badsum), затем реальный, разрезанный по имени сервера | сочетание фейка и разреза внутри SNI |
| `disorder-sni.json` | реальный разрез по SNI, части в обратном порядке | рассинхрон без фейка (disorder) |
| `fake-disorder-sni.json` | фейк (badsum), затем реальный разрез по SNI в обратном порядке | фейк плюс disorder |
| `md5sig-fake.json` | фейк с низким TTL (6) и опцией TCP MD5 Signature (неверная подпись), затем реальный | DPI впитывает фейк с MD5-опцией, но тот умирает по TTL до сервера. Низкий TTL обязателен: если bad-MD5 сегмент долетит до строгого сервера (напр. Google front), он отвечает RST и рвёт соединение. TTL подбирается под число хопов до DPI. Только `--mode intercept` |
| `ipv6-hopbyhop-fake.json` | фейк с заголовком расширения IPv6 Hop-by-Hop, затем реальный | рассинхрон разбора: DPI может не дойти за цепочкой расширений до TCP/SNI. Действует ТОЛЬКО на трафик IPv6; на IPv4 приём неисполним и пропускается. Только `--mode intercept` |
| `tcp-overlap-cover-variant.json` | `tcp_overlap` с cover-пресетом на другом SNI (`tls_cover_681_yandex`) | то же перекрытие, что у CDN в `config.json`, но cover несёт SNI ya.ru вместо google. Варианты (`_apple`, `_microsoft`, `_yandex`) взаимозаменяемы — все ровно 681 байт — и нужны, чтобы один google-cover не стал сам сигнатурой обхода. Только `--mode intercept` |

Это кандидаты, а не гарантии: какой приём берёт конкретный DPI — выясняется
живым прогоном (для того и затевается автоподбор). TTL и длина фейка —
подбираемые параметры.

## Как проверять

Останови сторонние обходы (zapret и т.п.) — иначе измеряешь их, а не движок:

```
tasklist | findstr /I "winws zapret goodbyedpi"
```

Для каждого кандидата:

```
:: окно от администратора:
evasion.exe run --mode intercept --config examples\strategies\fake-badsum.json
:: другое окно:
curl -v https://youtube.com
curl -v https://example.com
```

- `youtube` прошёл рукопожатие (есть `HTTP/...`) — приём обошёл DPI;
- `Connection was reset` — не взял, пробуй следующий;
- `example.com` обязан оставаться `200` — это контроль побочного вреда.

Останов движка — Ctrl+C (перехват снимается, трафик в норму).
