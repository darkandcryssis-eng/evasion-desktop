# Библиотека прогонов

Прогон — это проверка на **живом движке**: собирается настоящий бинарник,
поднимается настоящий прокси, через него идёт настоящий трафик, и смотрится,
что получилось. Прогоны дополняют юнит-тесты, а не заменяют их.

## Почему это отдельно от юнит-тестов

Юнит-тесты проверяют **части** и живут рядом с кодом (`internal/**/*_test.go`),
потому что Go требует этого: тест в пакете видит неэкспортируемые функции, на
которых держится почти вся проверка (`classifyConn`, `foldName`,
`canonicalDomain`, `record`). Унести их отсюда нельзя — развалятся и доступ к
внутренностям, и `go test ./...`, и фаззинг, и проверка аллокаций.

Прогоны проверяют **путь к состоянию**, а не состояние. Именно поэтому они
нужны: в этом проекте трижды подряд проскакивали дефекты, которые все
юнит-тесты считали отсутствующими —

- ложная тревога об обвале портфеля при каждом запуске;
- восемь снимков на старте вместо одного;
- гонка между открытием слушающего сокета и публикацией первого снимка.

Все три видны только живьём, и все три нашлись чтением вывода запуска.

## Правила библиотеки

1. **Одна папка — один прогон.** Имя папки говорит, что проверяется:
   `archive-persists-observations`, а не `test3`.
2. **Запуск — одной командой:** `go run ./tests/<имя-папки>`.
3. **Прогон сам глушит средства перехвата** (zapret, GoodbyeDPI, byedpi) и
   **возвращает их обратно**. При работающем перехватчике измеряется сумма двух
   воздействий, и отличить «сработала наша стратегия» от «сработал zapret»
   нельзя. Возврат обязателен: zapret нужен владельцу для работы.
4. **Прогон не оставляет следов**: конфиг, состояние и журнал пишутся во
   временный каталог и удаляются.
5. **Прогон не требует, чтобы цели открывались.** Провал цели — это измерение,
   а не дефект. Падать прогон обязан только тогда, когда виноват движок.
6. **Общее — в `harness`.** Если два прогона делают одно и то же, это переезжает
   в `harness`, иначе прогоны разойдутся в мелочах и перестанут быть
   сравнимыми.

## Что есть сейчас

| Папка | Что проверяет |
|---|---|
| `tests-can-fail-under-mutation` | каждый тест из батареи падает при соответствующей мутации кода: тест, проходящий при сломанном коде, ничего не защищает |
| `proxy-applies-strategy-end-to-end` | стратегия доходит от конфига до соединения, исход возвращается в контур |
| `archive-persists-observations` | наблюдение с живого соединения попадает в журнал на диске и читается обратно после остановки движка |
| `probes-earn-evidence-without-user-traffic` | движок добывает наблюдения пробами, не пропуская через себя ни одного соединения пользователя |
| `interception-tools-stopped-and-restored` | средства перехвата обнаруживаются, глушатся и возвращаются (сам измерительный инструмент) |
| `targets-measured-without-interference` | цели конфига измеряются на чистой обстановке; контрольные цели обязаны уцелеть |
| `windows-full-check` | полный прогон владельца на Windows (`check.ps1`): статический анализ, тесты, фазы измерений, дамп пакетов |

## Как запускать

```
go run ./tests/run-all                       все прогоны по очереди
go run ./tests/targets-measured-without-interference   один прогон
```

Полный прогон для Windows (отдельно, ему нужен PowerShell):

```
powershell -ExecutionPolicy Bypass -File .\tests\windows-full-check\check.ps1
```

**Права администратора.** Остановка служб и процессов перехвата их требует. Без
них прогон не станет притворяться, что измерение чистое: он скажет, что
остановить не удалось, и завершится с ошибкой.

## Как добавить прогон

1. Папка с именем, описывающим суть, внутри `main.go` с `package main`.
2. Начать с `harness.StartRun(имя, что проверяется)` и `defer run.Finish()` —
   это само остановит перехватчики и вернёт их обратно.
3. Факты писать через `run.Fact`, несоответствия — через `run.Require`.
4. Добавить папку в список `tests/run-all/main.go` и строку в таблицу выше.
5. Если прогон заявляет неочевидное свойство продукта, добавить мутацию в
   `tests-can-fail-under-mutation` — иначе через полгода никто не узнает, что
   прогон перестал это свойство проверять.
