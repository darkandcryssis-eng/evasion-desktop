# Evasion UI

Десктопная оболочка движка `evasion` на Wails v2 (Go + React 18 + Vite +
TypeScript). Отдельный Go-модуль `github.com/fitting-1c/evasion-ui`: он не
импортирует пакеты движка (они в `internal/` корневого модуля), а несёт
собранный `evasion.exe` внутри себя и управляет им как подпроцессом.

Окно: рабочее — 1200 × 820 px, минимум — 760 × 540 px (значения в
`frontend/src/App.tsx`). Интерфейс адаптируется к ширине окна.

## ASCII edition — интерфейс из символов

Строго монохромные темы «бумага / графит», сохраняемые локально.
Командная навигация, символьные иконки, переключатели `[ × ]`, скобки
статусов и пунктирные разделители заменяют прежние карточки и пейзажи.
На главной — оригинальный объёмный узел из символов: Canvas 2D,
ограничение до 30 кадров/с, без WebGL и внешних ресурсов. Скульптура
медленно вращается и реагирует на курсор; переходы и типографические
детали продолжают движение на остальных экранах.
Графика учитывает `prefers-reduced-motion`, настройку анимаций и скрытие окна;
статичный режим не держит постоянный цикл отрисовки.
Подключение, Telegram, игры, диагностика и настройки используют прежнее Go API.
Статусы показывают состояние движка, а не обещают доступность сервиса без проверки.

## Что делает

- **Обзор** — запуск/остановка движка (`run --mode intercept`), выбор режима
  голоса и QUIC, режим наблюдения, перезапуск Discord с выключенным DoH; живая
  сводка разбора ClientHello.
- **Цели** — группы доменов из конфига и действующая на них стратегия.
- **Портфель** — содержимое `state\status.json` (только в режиме автопилота).
- **Диагностика** — проверки окружения (права, WinDivert, конфиг, память
  голоса `rtctrack`, конфликтующие копии движка, hosts) и запуск
  `evasion doctor --json`.
- **Настройки** — тема оформления, анимации, и доступ в один клик к папке
  данных (`%LOCALAPPDATA%\Evasion`).
- **Профили / VPN** — локальная персонализация оболочки.

Поведение окна и движка:

- **Один экземпляр.** Вторая копия Evasion.exe завершается, активная поднимает
  своё окно (SingleInstanceLock).
- **Зачистка при старте.** При запуске оболочки и перед каждым стартом движка
  глушатся чужие `evasion.exe` (от прошлой сессии или `start-discord.bat`) —
  иначе две копии дерутся за WinDivert handle и повторный запуск не поднимает
  движок.
- **Папка данных** — `%LOCALAPPDATA%\Evasion`: `state\` (rtctrack, lock,
  events), `runtime\` (движок, WinDivert, конфиг). Фиксированное место, не на
  рабочем столе и не рядом с exe; открывается из «Настроек».
- **Трей.** Крестик предлагает «Свернуть в трей» (окно скрывается, значок у
  часов; вернуть — клик по значку или «Открыть») или «Закрыть» (остановить
  движок и выйти). Обычное сворачивание в панель задач — отдельной кнопкой.
- **Иконка** — фирменные столбики-эквалайзер (`build/appicon.png` → окно и
  панель задач, `assets/tray.ico` → трей).

Управление движком идёт через подпроцесс: наблюдение — через `--json` на stdout
и slog-журнал на stderr; остановка — закрытием stdin (`--stop-on-stdin-eof`),
это на Windows заменяет Ctrl+C и не пропускает `defer` движка (освобождение
`engine.lock`, сброс `rtctrack`), в отличие от принудительного завершения.

## Встроенный пакет (`payload/`)

В единый `Evasion.exe` встраиваются (`go:embed`): `evasion.exe`, `config.json`
(копия `examples/config.json`), `WinDivert.dll` + `WinDivert64.sys` и лицензия
WinDivert. При первом запуске оболочка распаковывает их в `runtime\` рядом с
`Evasion.exe`. `state\` (в т.ч. `rtctrack.json`) движок держит рядом с
`Evasion.exe`: положите его в ту же папку, где раньше запускали
`start-discord.bat`, и прогретая память голоса подхватится.

В git лежит только `payload/README.md`; артефакты собирает скрипт.

## Сборка единого EXE

В **cmd.exe** на Windows (нужны Go 1.27 и Node.js):

```bat
cd ui
build-and-run.bat
```

Скрипт собирает `evasion.exe`, копирует конфиг, кладёт WinDivert (из корня
репозитория или официального релиза 2.2.2 с проверкой SHA-256), ставит `wails`
при необходимости и собирает `build\bin\Evasion.exe`, затем запускает его.

`Evasion.exe` помечен манифестом `requireAdministrator`: Windows спросит
повышение прав при запуске (WinDivert без прав администратора не ставит
драйвер), и движок-подпроцесс их наследует. На Windows 11 WebView2 уже есть; на
части Windows 10 его нужно установить отдельно.

## Разработка интерфейса

```bat
cd ui
dev-ui.bat
```

`wails dev` поднимает окно с горячей перезагрузкой фронтенда. Биндинги Go-API
(`frontend/wailsjs/`) Wails генерирует сам; в режиме `dev` прав администратора
может не быть — запуск движка тогда вернёт понятную ошибку.
